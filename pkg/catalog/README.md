# OpenMili 探测清单

公开注册表包含大纲的全部 522 项：前 11 章和第 13 章的 203 个本机、网络、协议、数据库及审计项目，加上第 12 章 319 个网页项目。测试在本地存在外部清单时会校验名称和顺序；发布包不依赖开发清单文件。

`Full()` 返回 522 项完整大纲，`All()` 返回第 12 章 319 个网页注册表，`Default()` 返回 18 个重点页面，`Categories()` 返回网页分类顺序。所有返回值均可独立修改；稳定 ID 用于配置覆盖和报告关联。

每项都带有 `Capability`、`Check` 和 `Reason`。本机可读取的系统、网卡、DNS、路由、端口和延迟指标由原生探针执行；需要外部测点、API Key、浏览器或协议握手的项目仍会出现在 `--full` 报告中，并在 JSON 的 `reason` 字段写明原因。

URL 是常见公开网页入口，标题片段是初始预期内容规则，未在开发期间向这些网站发送实测请求。站点可能改域名、地区跳转、页面语言或标题；检测器必须允许配置覆盖，并在证据不足时显示“无法判定”。品牌标题命中只能说明该网页满足初始规则，不能证明登录、模型调用、视频播放、交易或推送可用。

- WAF/CDN 供应商没有指定受保护测试页面，保留空 URL，显示“未测试（未配置入口）”；不能把供应商官网访问结果解释成该供应商所有客户的 IP 信誉。
- Telegram 各 DC、APNs、FCM 和 ghcr 不是普通网页检测项，保留空 URL，需要独立协议探针与对应条件。
- 不确定或变动的入口（如部分 AI 网站、BTC.com、维普等）保留空 URL，允许后续配置。没有配置的项目保留在全量报告中。
- 云服务、银行、游戏、微信等采用公开网页入口，仅判断该入口页面；网站正常不代表客户端或相应业务能力正常。
- 同一个公开页面可能属于两个清单项，例如 Google 搜索。调度器可在同一出口观测时复用采样证据，避免重复请求。

本注册表独立编写，不包含第三方项目代码、Cookie、会话材料、浏览器指纹或挑战处理代码。
